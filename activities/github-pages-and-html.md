You've made a repository and written markdown in it. Now you make it a website.

This is a first look at HTML, not a web development course. You will take those. The
point here is that the gap between "a file on my computer" and "a page anyone on the
internet can open" turns out to be about fifteen minutes, and knowing that changes what
you think you're allowed to build.

## What you'll do

Work through several small HTML files, changing things and seeing what happens, then
create a GitHub Pages repository and publish a site.

**Spend about an hour on it and submit what you have, finished or not.** This is honest
effort, not perfection. People come into this course from completely different starting
points, and that is the normal condition, not a problem with you. We go over the
solutions together next class.
