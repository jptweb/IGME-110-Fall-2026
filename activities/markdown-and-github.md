# Activity: Markdown and GitHub

**IGME-110 | Week TBD | In-Class Activity**

> 🚧 **Not scheduled.** Part of a keep-or-cut decision about the HTML and GitHub arc.
> This may or may not run in Fall 2026.

Markdown is how you write anything technical: documentation, READMEs, notes, issues,
half the tools you'll use in the next four years. It takes about twenty minutes to learn
and you will use it constantly.

GitHub is where that writing lives, and having touched it once before a required course
makes you assume it does is worth a lot.

## What you'll do

Learn the markdown you actually need (headings, lists, links, images, emphasis, code),
then make a repository and publish a listicle page in it. Something you care about,
because you'll be looking at it for a while.
