# IGME-110: Introduction to Interactive Media

**Fall 2026 | RIT School of Interactive Games and Media**

## Welcome

This repository holds most of the course materials: weekly notes, project instructions, and
in-class activities. **Use myCourses as the source of truth for deadlines**, and for links to
anything not kept here. GitHub is where the instructions live because it makes them easy to
maintain, share, and keep under version control.

Whether you're a Game Design & Development student, a New Media Interactive Development student, or taking this as an elective, this is your central hub for navigating the course.

## Course Overview

This course is a big-picture overview of interactive media, games included, covering everything
from social and legal aspects to the technical foundations of different media types. You'll
develop skills in:

- Research and information evaluation
- Critical analysis and argumentation
- Visual communication and design
- Interactive prototyping
- Digital media production (images, audio, video)
- Collaborative creation and peer critique

## Repository Structure

```
IGME-110-Fall-2026/
├── weekly/          # Class notes, one per session
│   ├── 1A.md        # Week 1, Tuesday
│   ├── 1B.md        # Week 1, Thursday
│   └── ...
├── documents/       # Syllabus and project instructions
├── activities/      # In-class activities
└── dashboard/       # Data for the myCourses homepage widget
```

`A` is Tuesday and `B` is Thursday, so `3B.md` is the Thursday of week 3.

**A note on how this works:** these files are pulled into myCourses automatically. If you spot a
mistake, tell me and it gets fixed everywhere at once. You're also welcome to read the raw files or
fork the repo and keep your own copy.
